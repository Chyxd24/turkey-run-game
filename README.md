**Turkey Trot: Escape the Harvest** — a side-scrolling chase. You are a turkey
running from the farmer: leap the wood-burning ovens, duck under the carving
knives that sweep in from the sky, and grab corn for points. Reach 4000 m and you
escape for good. Built with canvas 2D and plain ES modules — no libraries, no
assets, no network requests.

- `↑` / `Space` / `W` — jump
- `↓` / `S` — duck
- `←` / `→` / `A` / `D` — move
- Tap or click to steer on touch

## Run it

```sh
node serve.ts --port 8080
```

Then open http://localhost:8080. To build the judge's dossier locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
